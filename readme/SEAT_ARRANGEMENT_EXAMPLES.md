```
Date        | Time  | Course | Rooms
------------|-------|--------|------------------
2024-01-15  | 09:00 | CS162  | 101
```

```
Date        | Time  | Course | Rooms (Seats)
------------|-------|--------|------------------
2024-01-15  | 09:00 | CS162  | 101(70)
2024-01-15  | 09:00 | B1-HS151 | C002(120), 101(5)
```

**Interpretation**:
- CS162: 70 students in room 101
- B1-HS151: 120 students in room C002, 5 students in room 101

## How to Use These Examples

### For Administrators
1. **Capacity Planning**: See how students are distributed
2. **Room Assignment**: Verify room capacities are appropriate
3. **Schedule Optimization**: Check for room utilization efficiency

### For Exam Supervisors
1. **Print Seat Maps**: Use visual grids for room displays
2. **Verify Count**: Ensure student count matches seats
3. **Student Verification**: Check student IDs against seating

### For Students
1. **Find Your Room**: Look up your student ID in the seat arrangement
2. **Locate Your Seat**: Use row and column numbers
3. **Plan Arrival**: Know which room to go to in advance

---

## Printing Instructions

### For Room Display Boards

1. Open `exam_timetable.xlsx`
2. Go to "Seat Maps" sheet
3. Find your room section
4. Select the visual grid area
5. Print Selection (File → Print → Print Selection)
6. Post outside exam room entrance

### For Student Lists

1. Open `exam_timetable.xlsx`
2. Go to "Seat Arrangement" sheet
3. Find the exam course
4. Print the detailed seat list section
5. Distribute to students or post on notice board

## Color Coding (in Excel)

In the actual Excel file, you'll see:

- 🟦 **Blue Headers**: Room and exam information
- 🟩 **Green Backgrounds**: Room capacity information
- ⬜ **White Cells**: Student seat assignments
- 🟨 **Yellow Borders**: Visual grid boundaries
